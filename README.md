# __Spider-Robot__
This repository was made to showcase the fabrication of a robotic spider and scripts created for an on campus event for the CSUB IEEE Computer Society club. Since we are not an officially chartered Student Branch Chapter yet, this repository and the materials made do not reflect the actual IEEE organization.


## About
This repository was made for a two part event workshop, first a coding workshop to learn how to use arduino IDE and program based on your components, and second a building workshop to learn how to bring your ideas to life. The development of this project included reverse engineering an aliexpress Spider Robot. For this, we tested and developed our own version of the robot. This repository is a repository to showcase the project made, we are not claiming to know everything, this is a documentation guide of what we did and what worked out best. We will continue to update and expand all of our repositories to ensure that all of the components work best to our abilities.


## Disclaimer
For this project, the components and design were built to the best of our capabilites. For future works and imporvements of this design, please feel free to reach out in regards to either schematic, code, or fusion models. We will be updating this project as we will like to expand and build our designs for future students. We hope that this project helps you learn a little more in regards to coding, building, and putting your mind to the test. 


## Folders
- __Scripts Folder__
  -This folder includes scripts that were designed to follow for the spider used and developed for the workshop. The SCRIPTS.md file contains in in-depth explanation on what each script does, and how you can improve or better this script. Let us know on any improvements!
- __Build Folder__
  -This folder contains the stl files use to develop the final spider version used for the event. The DESIGN.md file explains more on the design and development of the cad models and what dimensions were used.
- __Components Folder__
  -For this project, we wanted this spider to be beginner friendly and something that anyone can build. We have outlined the entire process of the build, why we chose certain components and overall thoughts. All updates will be made throughout the process.
